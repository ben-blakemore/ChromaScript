# Dependencies

## Application

The application requires Linux, C11 and C++17 compilers, GNU Make, `pkg-config`
and the following development libraries. The Makefile checks for these libraries
before compiling.

| Dependency | Purpose | `pkg-config` name |
| --- | --- | --- |
| GLFW 3 | Windows, OpenGL contexts and input | `glfw3` |
| Lua 5.4 | Embedded DSL interpreter | `lua5.4`, `lua-5.4`, `lua54` or `lua` |
| PulseAudio client library | Live audio capture | `libpulse-simple` |
| OpenGL | Graphics API; the runtime requests OpenGL 3.3 core | `gl` |
| FFTW 3, single precision | Audio spectrum analysis | `fftw3f` |

Audio capture needs a running PulseAudio server or a compatible implementation,
such as PipeWire with its PulseAudio compatibility service. Rendering needs an
OpenGL 3.3 capable driver and a graphical desktop session.

Debian / Ubuntu:

```sh
sudo apt install build-essential pkg-config libglfw3-dev liblua5.4-dev libpulse-dev libgl-dev libfftw3-dev
```

The development environment inspected for this dependency list reports GLFW
3.3.10, Lua 5.4.6, libpulse 16.1 and FFTW 3.3.10. These are reference versions,
not an exact system package lockfile.

## Bundled source dependencies

These files are committed alongside the project. No separate installation or
network access is required to obtain them during a normal application build.

| Dependency | Version and location | Reason for including it |
| --- | --- | --- |
| [glad](https://github.com/Dav1dde/glad) | Generated by glad 2.0.6 for OpenGL 3.3 core; `third_party/glad/` | The generated loader is compiled directly by the Makefile |
| [doctest](https://github.com/doctest/doctest/tree/v2.4.12) | 2.4.12; `third_party/doctest/` | Single-header framework used by the tests |

The glad generation options are recorded in `include/glad/gl.h`; keep the
generated files together. The doctest header and its licence are retained
unchanged. Preserve the licence and attribution notices in both dependencies.

The headless application tests require the C++ compiler, Make, `pkg-config`, Lua,
FFTW and the bundled doctest header. They do not open an audio stream or window.
